Open a PDF to get started

Drop a file anywhere, or choose Open. Open several PDFs at once and each gets its own tab.

  • Pick a tool, then click-drag on the page: Text, Callout, Line, Rectangle, Ellipse, Highlighter.
  • Polygon, Polyline, Cloud and Measure Area: click each corner, then click the ✓ (or double-click) to finish.
  • Select / Move lets you reposition anything and edit it in Properties.
  • Copy a text box in one tab and paste it into another.
